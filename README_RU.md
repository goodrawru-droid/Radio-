# ARK Radio — Android

Обновлённый исходный проект Android-приложения для Zaycev.FM.

## Что изменено

- Вместо 55 строк с выдуманными вариантами адресов оставлены 17 разных каналов с прямыми ссылками на аудиопотоки, опубликованными в справочниках радиопотоков. Провайдер может менять адреса и доступность каналов, поэтому перед релизом их нужно проверить на целевом телефоне.
- Статус плеера меняется по событиям Media3: подключение, воспроизведение, пауза и ошибка.
- При ошибке воспроизведения отображается сообщение вместо бесконечного «Подключение к потоку…».
- Добавлена собственная панель эквалайзера: до пяти полос частот, уровни в децибелах, доступные пресеты и сброс. Она управляет Android Equalizer, подключённым к аудиосессии ExoPlayer. Наличие и возможности аудиоэффекта зависят от прошивки телефона.
- Избранные станции сохраняются в SharedPreferences после закрытия приложения.
- Оставлены тёмная тема, поиск, фильтр по жанрам и фоновый MediaSessionService.

## Сборка APK через GitHub Actions

1. Загрузите содержимое этой папки в корень GitHub-репозитория. В корне должны находиться `settings.gradle.kts`, `build.gradle.kts`, папка `app/` и папка `.github/`.
2. Откройте вкладку **Actions** и запустите workflow **Build ARK Radio APK**.
3. Когда запуск завершится зелёной галочкой, откройте его страницу и найдите **Artifacts**.
4. Скачайте `ARK-Radio-debug-apk.zip`, распакуйте его. APK называется `app-debug.apk`.

## Важно

Этот архив содержит исходный проект, а не готовый APK. В текущей среде Android-сборка не запускалась. Успешную компиляцию и работу всех потоков необходимо подтвердить в GitHub Actions и на телефоне. Ссылки на радиопотоки могут меняться со стороны Zaycev.FM.

## Обновление интерфейса v3
- На широком экране список станций и категории находятся слева, плеер с анимированной спектрограммой — по центру.
- На телефоне в портретном режиме интерфейс автоматически перестраивается в одну колонку, чтобы элементы не были слишком узкими.
- Добавлены быстрый выбор станций, кнопка избранного в карточке плеера, экран «О приложении» и собственная иконка ARK Radio.
- Спектрограмма анимированная и декоративная: она реагирует на состояние воспроизведения, но не анализирует реальный аудиосигнал.

## Прототип каталога плейлистов (v4)

В интерфейс добавлено окно «Плейлисты» с вложенной навигацией: жанр «Рок» → поджанр → одна из пяти тестовых подборок. Поджанры: классический рок, альтернативный рок, хард-рок, панк-рок и зарубежный металл. Подборки можно сохранять в локальную библиотеку приложения.

Важно: названия подборок в этой версии — демонстрационная структура интерфейса, а не автоматически полученные данные Zaycev.net. Реальные плейлисты и треки пока не загружаются. Для следующего этапа нужно проверить доступный официальный интерфейс/разрешённый источник данных Zaycev.net. Кнопки скачивания намеренно не добавлены до подтверждения доступности и условий загрузки аудиофайлов.

## Подключение реального каталога и скачивания (обновление v4.1)

- В окне плейлистов добавлена кнопка перехода на официальный `https://zaycev.net/`, где доступны реальные сборники и загрузки согласно условиям самого сервиса.
- Локальные названия рок-подборок по-прежнему являются демонстрационными. Они не подменяют реальные треки и не запускают фиктивное воспроизведение.
- В публичных материалах, которые удалось проверить, не обнаружен документированный открытый API для получения каталога треков, прямых MP3-ссылок и пакетного скачивания плейлистов. Поэтому приложение не пытается обходить авторизацию, защиту или ограничения сервиса.
- Радио использует отдельные прямые потоки Zaycev.FM. Поток радио не является отдельным MP3-файлом, поэтому нельзя безопасно реализовать скачивание «трека из эфира» без официальных метаданных и разрешённого URL загрузки.
