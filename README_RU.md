# ARK Radio — исходный Android-проект

**APK не собран и не проверен.** Это исходный проект с облачным workflow сборки.

## Возможности исходного прототипа
- Android 14–16: target SDK 35; сборка с JDK 17 и Gradle 8.9.
- Compose-интерфейс в тёмной теме.
- Категории, поиск, избранное (пока только в памяти процесса).
- Media3 ExoPlayer в `MediaSessionService`: фоновое воспроизведение и системное медиа-уведомление/контролы.
- Интеграция с системной панелью аудиоэффектов и Android `Equalizer` API.

## Каталог — важное предупреждение
В каталоге 55 записей-кандидатов, но **это не 55 проверенных уникальных станций**. Первые 10 адресов вида `https://abs.zaycev.fm/<жанр>256k` — известные кандидаты; остальные построены как варианты хоста/битрейта и могут не существовать. Прямые потоки могут меняться или ограничиваться провайдером. Перед релизом обязательно проверьте каждый URL, удалите нерабочие записи и не называйте их подтверждёнными каналами.

## Облачная сборка APK через GitHub Actions
1. Создайте пустой репозиторий на GitHub.
2. Загрузите содержимое архива в корень репозитория, включая скрытую папку `.github`.
3. Откройте **Actions** и разрешите workflow, если GitHub запросит.
4. Запустите **Build ARK Radio APK** вручную либо отправьте commit в `main`/`master`.
5. После успешного завершения откройте запуск workflow, секцию **Artifacts**, скачайте `ARK-Radio-debug-apk`.
6. Распакуйте артефакт: внутри должен быть `app-debug.apk`. Только после успешного workflow и установки на устройство можно считать APK собранным/проверенным.

Workflow скачивает Gradle 8.9 и использует JDK 17. Нужен доступ к GitHub, Google Maven и Maven Central.

## Установка и проверка
1. Перенесите `app-debug.apk` на телефон и разрешите установку из выбранного источника, если Android спросит.
2. Запустите приложение и попробуйте несколько потоков.
3. Проверьте уведомление управления, блокировку экрана, переключение приложений и работу эквалайзера.
4. Если поток не открывается, проверьте сам URL отдельно: приложение не может исправить недоступный сервер.

## Ограничения прототипа
- Исходники не компилировались в этой среде; возможны ошибки сборки, которые потребуется исправить в Actions.
- APK не приложен.
- Избранное не переживает перезапуск приложения.
- Собственная UI-панель эквалайзера отсутствует: открывается системная панель, если прошивка её предоставляет. На некоторых устройствах настройка недоступна.
- Обработка ошибок/повторного подключения пока минимальна.
- Перед публичным распространением проверьте условия использования бренда и права на ретрансляцию.

## Основные файлы
- `Station.kt` — каталог.
- `ArkPlaybackService.kt` — фоновый медиасервис.
- `MainActivity.kt` — интерфейс.
- `.github/workflows/android.yml` — облачная сборка.
